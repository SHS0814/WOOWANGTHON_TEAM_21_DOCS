## 바꾼 것

- **제목과 섹션:** 제목을 작게(24) 했습니다. 섹션 제목은 작은 회색 글자 4개(가족, 약통과 시각, 알림과 사진, 연결된 폰)이고, 그 아래 항목은 모두 구분선이 있는 **한 줄 행**(높이 52 이상)입니다.
- **어르신 호칭:**
  - 행 오른쪽에 현재 값("어머니 ›")이 보이고, 부제는 "어르신 화면에 보이는 내 이름: 민지"입니다(기존 문구 유지).
  - 누르면 아래에서 **편집 시트**가 올라옵니다. 입력칸, 안내 "어르신 화면의 말은 이 호칭으로 나와요", 취소와 "호칭 저장" 버튼이 있습니다.
  - 저장 버튼은 값이 비었거나 바뀌지 않았으면 꺼집니다.
- **약통과 시각:** 복약 시각 바꾸기, 약통 다시 등록, 약통 채우기 세 행이고, 보조 설명 없이 한 줄입니다.
- **약 칸이 그대로일 때, 사진 보관 기간:**
  - 행 오른쪽에 현재 값이 보입니다("안내 후 다시 찍기" 또는 "바로 알리기", "90일").
  - 누르면 **선택 시트**가 올라오고, 기존 라디오 문구와 설명을 그대로 씁니다. 고르면 바로 저장되고 시트가 닫힙니다.
- **확인이 필요할 때 알림:** 상태 칩 대신 부제 앞에 상태 글자를 둡니다(상태 색 굵게, 종 아이콘도 같은 색). 그 뒤에 기존 안내 문구가 이어집니다. 받는 중일 때는 한 줄입니다.
- **하루 요약 알림:** 스위치 한 줄이고, 부제 "켜짐" / "꺼짐: 요약은 앱 안에서만 보여요"는 그대로입니다.
- **연결된 폰:** 한 줄 행 오른쪽에 작은 "해제" 버튼(높이 48)을 둡니다. 어르신 폰 알림 꺼짐 경고와 "어르신 폰 연결" 행은 기존 조건 그대로입니다.
- **저장 반영:** 저장하면 값이 바로 행에 반영되고, 실패하면 원래 값으로 되돌리고 오류 글자를 보여 줍니다. 웹 모의에서 호칭, 칸 그대로, 보관 기간을 바꾼 뒤 다시 불러와도 유지되는 것을 확인했습니다.
- **키보드:**
  - 시트는 `KeyboardAvoidingView` 안에 있습니다. iOS는 `padding`으로 시트를 키보드 위로 올립니다. Android는 모달이 adjustResize로 줄어들어, 화면 아래에 붙은 시트가 키보드 위로 올라가는 구조입니다.
  - 입력칸과 저장 버튼이 시트 위쪽에 있어 가려지지 않게 했습니다. 실제 폰 키보드 확인은 못 했으니 확인을 부탁드립니다.
- **유지한 규칙:** 본문 16 이상, 터치 44 이상, 상태는 글자와 함께 써서 색만으로 구분하지 않습니다.
