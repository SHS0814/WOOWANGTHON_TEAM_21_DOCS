## 바꾼 것

- **1줄:** 날짜(같은 날 둘째 행부터 흐리게, 오늘은 "오늘") · 시간대 · 예정 시각 `HH:MM`, 그리고 **오른쪽 고정 칸**에 상태(기호 + 짧은 글자).
  - 상태는 정상, 드심, 안 드심, 확인함, 예정, 진행 중, **확인 필요**(열린 인계) 중 하나입니다.
  - 열린 인계는 예전에는 사유 전체("답이 없으셨어요")를 썼지만, 이제 "확인 필요"로 줄이고 사유는 2줄로 보냅니다.
- **2줄:** 기록 시각 `HH:MM 기록` · 판정자(`AI` 또는 `민지 판정`) · ⚠ 사유 짧은 이름표, 그리고 **오른쪽 고정 칸**에 보라 바탕 흰 글자 "모의", "시뮬".
  - 기록·판정·사유가 모두 없으면 "아직 복약 시각 전", "기록 없음", "기다리는 중" 중 하나를 써서 항상 2줄입니다.
- **사유 짧은 이름표:**

  | 사유 | 짧은 이름표 |
  |---|---|
  | no_response | 무응답 |
  | unclear | 애매 |
  | unchanged | 칸 그대로 |
  | double_suspected | 이중 의심 |
  | refill_unconfirmed | 약통 확인 |
  | refill_overdue | 확인 불가 |

  - 리필 확인 요청만 있어 handoff가 null인 검색 결과(R-052)는 "약통 확인"으로, 사유별 검색이면 검색한 사유의 짧은 이름표로 표시합니다.
- **넘칠 때:** 두 줄 모두 `numberOfLines={1}`이라 넘치면 왼쪽 글자만 말줄임합니다. 상태와 모의·시뮬 표시는 오른쪽 고정 칸(`flexShrink: 0`)이라 잘리지 않습니다.
- **화면 낭독:** 줄이지 않은 전체 문장을 읽습니다.
  - 예: "10월 18일 (일) 아침 오전 8시 예정, 확인했어요, 민지 판정, 약 칸이 그대로예요, 약통을 채우셨나요?. 인계 자세히 보기"
  - 모의는 "모의 결과, 실제 AI 아님", 시뮬은 "시뮬레이션, 실제 복약 시각 알림 아님"으로 읽습니다.
