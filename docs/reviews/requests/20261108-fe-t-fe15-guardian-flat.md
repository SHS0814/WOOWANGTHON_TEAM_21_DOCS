## 바꾼 것

공용 부품(`src/components/guardian/ui.tsx`)에서 한 번에 바꿔 보호자 화면과 처음 설정 화면 전체에 같은 방식이 적용됩니다.

| 부품 | 전 | 후 |
|---|---|---|
| `Card` → `Section` | 회색 바탕 위 흰 카드 (테두리·그림자·둥근 모서리) | 상자 없음, 아래에 얇은 구분선 하나 |
| `ListGroup` | 흰 카드 안 행 목록 | 상자 없음, 행 사이와 끝에 구분선 |
| `Notice` | 색 바탕 + 테두리 상자 | 왼쪽 색 막대 + 아이콘 + 글자 (색만으로 구분하지 않음) |
| 바탕 (`guardian.color.bg`) | `#F2F4F7` | `#FFFFFF` 한 면, 구분선 색 `line #DCE1E8` 추가 |

- 구획은 모두 "아래 구분선 하나"로 끝나므로, 구획이 이어져도 선이 겹치거나 상자가 상자 안에 들어가지 않습니다.
- 홈 "확인할 일": 빨간 테두리 카드 대신 구분선 목록 행입니다. 빨간 아이콘과 빨간 제목으로 표시하고, 시뮬레이션 표시는 행 안에 그대로 둡니다.
- 인계 상세: 맨 위 빨간 테두리 카드 대신 빨간 아이콘과 빨간 제목을 씁니다.
- 역할 선택: 카드 두 장(파란 채움 1장 포함) 대신 아이콘이 있는 구분선 행 두 줄입니다.
- 유지한 것: 요약 숫자, 진행 막대, 상태 칩, 하단 고정 버튼, 하단 탭. 사진과 약통 격자는 내용 자체가 상자라 그대로 둡니다. 모의·시뮬레이션 표시(보라 칩, 검은 시뮬레이션 띠, 상단 모의 띠)도 그대로입니다.
- 덧붙임: 홈 요약 칩 "확인할 일 n건"을 "오늘 확인할 일 n건"으로 바꿨습니다. 아래 목록 건수에는 지난 날 것도 들어가서 헷갈릴 수 있어서입니다.
