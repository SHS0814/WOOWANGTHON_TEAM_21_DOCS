# 검토 요청: T-FE23 어르신 연결 화면 키보드 가림 수정

- 요청자: FE 에이전트
- 날짜: 2026-11-08
- 근거: R-067 (오류는 어르신 화면에서도 고친다, 디자인은 그대로)
- 브랜치: `fe/elder-connect-keyboard` 커밋 `3e42f2c` (FE main 392a554 기준, main 병합 안 함)
- 바꾼 파일: `src/app/elder/connect.tsx`, `src/components/Screen.tsx`, `src/lib/keyboard.ts`(새 파일), `src/components/guardian/ui.tsx`(훅을 옮긴 것뿐)
- JS만 바꿔 재빌드는 필요 없고, 새 의존성도 없습니다.

## 문제

- E2 연결 화면은 카메라 권한을 허용하면 정사각형 카메라 화면이 위에 있어서, 6자리 입력칸과 "숫자로 연결" 버튼이 화면 아래쪽에 옵니다.
- Android 15+는 화면이 상태바·내비게이션바 뒤까지 그려지는 방식(edge-to-edge)이라 키보드가 떠도 창이 줄지 않습니다. 그래서 숫자 키보드가 입력칸과 버튼을 가립니다. T-FE22a와 같은 원인입니다.

## 고친 것

- **`Screen`(어르신 공용) 옵션:** `keyboardAware` 옵션을 추가했습니다(기본 꺼짐).
  - 끄면 이전과 **같은 코드 경로**(`PlainScreen`)를 그대로 탑니다. 키보드 리스너도 붙지 않습니다.
  - 켜면 `KeyboardScreen`이 키보드가 화면 아래를 가리는 만큼 아래 여백을 줍니다. 키보드가 없을 때 모습은 같습니다.
  - 입력이 있는 화면에서 스크롤할 수 있게 `scrollRef` 옵션도 추가했습니다.
- **E2 연결 화면:** `keyboardAware`를 켰습니다. 숫자 입력칸에 포커스된 채 키보드가 뜨면 맨 아래로 스크롤해서, 입력칸과 "숫자로 연결" 버튼(그리고 오류 문구)이 키보드 위에 보입니다.
- **훅 위치 이동:** T-FE22a의 키보드 겹침 훅을 `src/lib/keyboard.ts`로 옮겼습니다. 어르신 컴포넌트가 보호자 `ui.tsx`에 기대지 않게 하려는 것입니다. 보호자 `ui.tsx`는 같은 훅을 가져다 다시 내보내므로 동작은 같습니다.
- **디자인:** 글자 크기, 72pt 버튼, 배치, 문구는 바꾸지 않았습니다. 웹 빌드에서 키보드가 없는 모습이 이전과 같은 것을 확인했습니다.

## 다른 어르신 화면 영향

- `grep -rln "TextInput\|GField" src/app/elder src/components/*.tsx` 결과는 `src/app/elder/connect.tsx` 하나뿐이었습니다. 입력칸이 있는 어르신 화면은 연결 화면뿐입니다.
- `Screen`을 쓰는 나머지 어르신 화면들은 `keyboardAware`를 켜지 않습니다. 그래서 수정 전과 같은 코드(`PlainScreen`)로 그려지고, 영향이 없습니다.

## 폰 확인 부탁 (어르신 앱 kr.dementiacheck.app, Android 15+)

연결 화면에서 카메라를 켠 상태로 6자리 입력칸을 누르면, 입력칸과 "숫자로 연결" 버튼이 키보드 위에 보여야 합니다. 키보드를 내리면 원래 모습으로 돌아와야 합니다.
